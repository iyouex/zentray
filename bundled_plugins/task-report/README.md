# task-report — 任务报告（示例插件，api_version 2）

任务完成时自动运行的示例插件：回显注入的任务上下文环境变量
（`ZENTRAY_TASK_*`），并输出 `RESULT` 摘要。

`write_back: true` 已开启——运行结束的 RESULT 文本会写回任务备注；
任务已归档（task_done 触发的常态）时追加到当日归档日志。

## 触发与授权

- manifest 声明 `triggers: [{type: event, event: task_done}]`。
- 首次自动触发时弹出一次性授权询问；拒绝后持久不再询问，
  可在 插件中心 → 该插件的「自动运行」开关重新打开。

## 手动测试

托盘 🧩 插件 → 任务报告 → 运行（手动运行无任务上下文，相关变量为空）。
完整链路：完成一个关联了本插件的任务 → 授权弹窗 → 自动运行 →
任务备注/归档日志出现写回行 → 插件中心「运行历史」可见记录与日志。
