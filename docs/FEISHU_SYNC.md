# 飞书同步配置（自建应用）

把 ZenTray 任务**单向推送**到飞书：带截止/提醒的任务进「ZenTray」日历，全部活跃任务进「ZenTray」任务清单；完成/删除自动撤下，**不在飞书侧回读**。与「飞书机器人」通知（群 webhook）相互独立。

## 1. 创建自建应用

1. 打开[飞书开放平台](https://open.feishu.cn/) → **开发者后台** → **创建企业自建应用**（名称随意，如 `ZenTray 同步`）。
2. 进入 **凭证与基础信息**，拿到 **App ID** 与 **App Secret**。
3. **权限管理** 开通以下权限（搜索权限名或点批量开通）：

   | 权限 | 用途 |
   |------|------|
   | `calendar:calendar` | 查看、创建、编辑日历及日历事件（建「ZenTray」日历、推日程） |
   | `task:task` | 查看、创建、编辑、删除任务（建「ZenTray」清单、推任务） |

4. **版本管理与发布** → 创建版本并申请发布（企业管理员审核通过后生效；未发布的应用调用会报权限错误）。

## 2. ZenTray 侧配置

托盘 **设置 → 📋 任务 → 飞书同步**：

1. 打开**启用飞书同步**，填入 App ID / App Secret。
2. 按需保留子开关：**同步日程到日历**、**同步任务到清单**。
3. 点**测试连接**（会先保存本卡片配置）：依次验证凭证 → 建/找日历 → 建清单，成功即配置完成。
4. 首次使用或远端状态错乱时点**全量重同步**：清空本地远端引用后把全部活跃任务重新入队推送。

**接收人 Open ID（可选）**：填某成员的 `open_id` 后，日历会自动共享给 TA、任务会指派给 TA（任务才会出现在 TA 的飞书客户端）。留空则只写入应用自身的日历/清单，管理员在飞书后台可见。open_id 可在开放平台 **API 调试台** 以本人身份调任意接口从返回中获取。

## 3. 同步规则

| 本地操作 | 飞书侧效果 |
|----------|-----------|
| 新建/编辑（含子任务、提醒调整） | 日历事件 + 清单条目创建或更新（本地记远端 id，幂等） |
| 带截止或提醒的任务 | 进日历：截止+提醒 = 定时事件（30 分钟）；仅截止 = 全天事件；仅提醒 = 当日定时 |
| 完成 | 清单条目标记完成，日历事件删除 |
| 废弃 | 清单条目与日历事件删除 |

推送失败不打断本地操作：错误记入「同步状态」行（`最近错误`），恢复正常后自动清除。

## 4. 故障排查

- **`code=99991672` / token 失效**：App ID/Secret 有误，或应用被停用。
- **无权限（code=230002 等）**：权限未开通或**版本未发布**——回第 1 节第 4 步。
- **看不到日历/清单**：没填接收人 Open ID（应用自身日历需管理员后台查看），或共享失败见同步状态错误。
- **全量重同步后出现重复**：重同步不清理远端旧对象；需要干净重来时先在飞书侧清空「ZenTray」日历与清单再点重同步。
