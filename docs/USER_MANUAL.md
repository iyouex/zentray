## 1. 产品是什么

系统托盘常驻的个人效率工具：**无主窗口**。

| 能力 | 说明 |
|------|------|
| 顶栏看板 | 活跃任务标题轮播；左：优先级饼图（色=紧急程度，填充=进度） |
| 任务 | 新建、编辑、进度、完成、废弃；分类、截止、提醒 |
| 周期任务 | 日/周/月自动派发 |
| 番茄钟 | 左：番茄饼图随倒计时填充；右：倒计时或自定义文案 |
| 闪电添加 | 全局热键快速记待办 |
| AI | 每日计划 + 每日复盘（可分别开关与调度） |
| 通知 | 应用弹窗 + WxPusher（可同时开） |

**习惯：**

- 启动后请看**屏幕顶栏/托盘**，不要找主窗口。  
- **右键托盘图标**打开菜单。  
- 关闭对话框 ≠ 退出；退出请用菜单「退出程序」。

## 2. 通用概念

### 2.1 任务饼图（非番茄）

扇形填充 = 当前任务的**子任务完成比例**（10% 步进；无子任务为空饼）。

| 完成度 | 外观 |
|------|------|
| 0% | 半透明色圆 + 描边 |
| 10%～90% | 同色实心扇形填充 |
| 100% | 实心满圆 |

| 优先级 | 颜色 |
|--------|------|
| 高 | 红（**无**绿点） |
| 中 | 黄 |
| 低 | 绿 |

### 2.2 番茄钟图标

- 与菜单 🍅 同语义：**红果 + 绿萼**。  
- 果体随专注进度饼状填充（已消耗时间比例）。  
- 右侧文字：设置中可选 **倒计时** 或 **自定义文案**。

### 2.3 标题前缀

- 分类：成对括号包住 `一级-二级`，如 `[工作-需求]`。  
- 逾期：可配置前缀如 `【已逾期】`。

### 2.4 数据目录

| 系统 | 路径 |
|------|------|
| Linux | `~/.local/share/ZenTray/` |

主要：`active_tasks.json`、`settings.json`、`periodic_templates.json`、`archive/`、`reviews/`、`icons/`、`zentray.log`。

## 3. 安装（Ubuntu / Debian）

### 安装前

- [ ] amd64 桌面环境  
- [ ] 建议：AppIndicator（`gir1.2-ayatanaappindicator3-0.1`、`python3-gi`）  
- [ ] 可选：`libnotify-bin`

### 安装

```bash
sudo apt install -y ./zentray_*_amd64.deb
zentray
```

### 注意

- 仅图标无文字：安装/启用 AppIndicator 支持。  
- 再点桌面图标：只刷新托盘，不新开进程。  
- Wayland 下热键可能不可用，请用托盘菜单。

> 其他平台（Windows / macOS）支持已从代码中移除，托盘层保留扩展点，恢复开发时按平台加回实现即可。

## 4. 日常使用

### 启动节奏

1. 刚启动：仅应用图标。  
2. 片刻后：饼图 + 任务标题轮播。

### 任务

- 菜单「📋 任务列表」打开任务列表页：**活跃 / 周期 / 历史** 三视图页签；点选卡片后右侧详情面板管理**子任务**（输入框回车添加、逐项完成/废弃，完成度自动汇总为彩色进度条），并可**编辑 / 完成 / 废弃**任务；页内「＋ 新建」按钮新建任务，周期模板可预设子任务。  
- 快捷键闪电添加：`Ctrl+Alt+T`。  
- **弹窗提醒冲突**：保存任务时若开启弹窗提醒，会检查是否与其它任务/周期模板弹窗，或「每日计划/复盘」调度时刻相同；有冲突时列出明细，确认后仍可保存。

### 番茄钟

1. 菜单「🍅 专注 N 分钟」。  
2. 顶栏左：番茄饼图进度；右：倒计时或文案（见设置）。  
3. 可延长 / 中止。

### AI

- **每日计划 / 每日复盘** 在设置中分别开关与设定时间（到点或之后会补跑一次/天；改时刻后按新时间可再触发）。  
- 多 API 配置时，**只能启用一个**。  
- 调度状态记在数据目录 `ai_schedule_state.json`（勿手改除非排查问题）。  

**场景能力**（设置 → AI 能力 顶部开关，默认全部关闭，开启后入口即刻出现）：

- **✨ 智能解析**：快速添加（`Ctrl+Alt+T`）与任务表单页。输入一句话（如「明天下午三点开版本评审会，要带灰度数据」）点 ✨，AI 生成草稿预览——标题/分类/优先级/截止/提醒/子任务逐项确认后应用。快速添加中「确认添加」直接建任务；表单中「应用到表单」回填各字段（分类按名称匹配，匹配不上保持当前）。
- **📷 图片识别**：任务表单页点「图片识别」选图，或直接 **Ctrl+V 粘贴截图**。识别出多条时先选一条，再进草稿预览。
- **💡 任务建议**：任务列表选中任务后，右卡顶部「AI 建议」给出优先级/截止/拆分等建议——带「应用」按钮的一键生效（提级/改截止/追加子任务），纯文本提醒（复盘/清理）仅展示，「忽略」逐条消掉。

### 退出

托盘菜单 → 退出程序。

## 5. 设置

### 窗口行为

所有应用窗口：
- **默认居中显示**：打开时自动出现在屏幕中央
- **可拖拽移动**：点击窗口任意空白位置即可拖动（避开按钮、输入框等交互区域）
- **拖动后不回弹**：同一窗口拖动后不会再被拉回中心（重新打开的新窗口仍默认居中）

左侧导航：

| 页 | 内容 |
|----|------|
| **✨ AI 能力** | 顶部**场景能力开关卡片**（智能解析 / 图片识别 / 任务建议，默认关）；下方标签页：每日计划、每日复盘、模型接入（多 API 折叠行，同时启用一个） |
| **🔔 通知** | 固定渠道：应用弹窗、WxPusher（可同时开，点击行展开配置） |
| **📋 任务** | 各优先级停留秒数、模式；逾期轮播与前缀 |
| **🍅 番茄钟** | 时长、延长；托盘右侧显示倒计时/文案 |
| **🧩 插件** | 总开关 + 运行前确认；三大折叠块：**导入插件**（zip/目录，预览校验后安装）、**插件列表**（排序/调度规则/参数预设/授权/运行）、**运行历史**（运行ID/起止/日志） |
| **🏷️ 分类** | 一二级增删改；括号成对选择 |
| **🖥️ 系统** | 外观（主题/动效/形状风格）、开机自启 |
| **💾 备份** | 五卡片：备份存储目录、手动即时备份、自动周期备份策略、从备份文件恢复、历史备份快照 |
| **📜 历史** | 只读单页：日期侧栏 + 合并时间轴 + 详情 |

通知渠道固定为 **应用弹窗** 与 **WxPusher**（不可自增删，可开关）。

## 6. 插件

### 6.1 开启与设置页结构

1. 托盘菜单 → **设置** → **🧩 插件**。
2. 打开 **启用插件**（下方「运行前确认」建议保持开启），保存设置。

启用后内置与用户插件目录**恒扫描**（单一总开关，无分项加载开关）。插件管理都在设置页，
按**三大折叠块**组织（导入插件 / 插件列表默认展开，运行历史默认折叠）：

| 折叠块 | 功能 |
|--------|------|
| **📦 导入插件** | 一个切换按钮选 **zip 包 / 目录**；路径输入默认填内置插件目录（便于复制改造示例）；**先预览校验，成功提示后才能点安装**；同名重复安装会询问覆盖；「高级」里可改用户插件目录（安装目标，留空 = 数据目录 `plugins/`） |
| **📜 插件列表** | 按 **更新时间 / 名称 / 分类** 正序或倒序排序，纵向滚动；每插件可展开编辑**调度规则**与**参数预设**，并有授权开关与运行/服务按钮；校验失败明细在列表下方 |
| **🗂 运行历史** | 最近运行：**运行ID / 插件 / 触发 / 起止时间 / 结果 / 摘要**；点行打开日志抽屉 |

手动复制目录到用户插件目录同样有效（点「刷新」即重扫）。

### 6.2 调度规则与参数预设

- **调度规则**：展开插件即可编辑触发规则（每日 / 间隔 / cron / 事件，可加多条），保存后
  **即时生效**；自定义保存在设置里（`ops.trigger_overrides`），**不改动插件文件**——zip
  重装升级不丢；「恢复默认」回到 manifest 声明。
- **参数预设**：声明了入参的插件（见 [插件规范](plugins/PLUGIN_SPEC.md) 3.5）可展开保存
  每个参数的预设值（单组，存 `ops.param_presets`）。运行取值优先级：
  **显式传入 > 预设 > 缺省值**；自动触发按 预设 > 缺省 取值。

### 6.3 自动触发与授权

插件可在 manifest 声明触发器（设置页的调度规则是对它的覆盖）：

- **每日定时**（错过补跑一次）、**间隔循环**、**cron 表达式**；
- **事件**：任务完成 / 番茄结束 / 启动时。

带触发器的插件首次自动运行前弹**一次性授权**：允许后静默自动运行；拒绝则不再询问
（插件列表该插件的授权开关可重新打开）。番茄钟进行中或已有脚本运行时，
到点的触发静默跳过（不弹通知）。开启了 `write_back` 的插件还会把结果写回任务备注。

### 6.4 运行

| 类型 | 托盘菜单行为 | 顶栏 |
|------|----------|------|
| **脚本（无入参）** | 按确认开关弹「确定运行」 | 进度文案（`⚡ …`）**暂时替代**任务轮播；结束后恢复 |
| **脚本（有入参）** | **参数弹窗**：预填 预设→缺省值，可修改后运行（取消即中止） | 同上 |
| **服务** | 启动 / 停止 / 状态 | 短通知提示，不占用轮播 |

- 脚本运行中不能开番茄钟；番茄进行中不能跑脚本（双向拦截，菜单同步置灰）。
- 菜单「📄 上次运行日志」可打开最近一次完整日志；历史与日志也可在
  **设置 → 🧩 插件 → 运行历史** 查看。
- 日志目录：数据目录下 `ops_runs/`。

### 6.5 任务关联插件

任务表单（新建/编辑）中可选择「关联插件」并就地试运行；任务详情右卡有「▶ 运行关联插件」
按钮（运行时自动带上该任务上下文，结果可在 **设置 → 🧩 插件 → 运行历史** 查看）。
周期任务同样支持——模板派发的实例会继承关联。

### 6.6 内置示例

| 插件 | 分类 | 说明 |
|------|------|------|
| **网络清理**（`net-cleanup`） | 网络 | 刷新 DNS/nscd/路由缓存（无权限跳过）、打印代理环境变量；不自动断 VPN 或改代理配置 |
| **任务报告**（`task-report`，v2） | 示例 | 任务完成时自动运行：回显任务上下文并把摘要**写回任务备注**——演示触发器 + 授权 + 写回全链路 |

完整说明见仓库 `bundled_plugins/<id>/README.md`。

### 6.7 与业务的关系

VPN 切换、邮箱相关等**具体操作**由你自己的插件实现；应用只负责发现、校验、触发与展示进度。可复制内置示例目录改 `id`/`run.sh` 作为模板。

## 7. 数据与备份

设置 → **💾 备份**，五张卡片：

1. **备份存储目录**：默认 `~/.local/share/ZenTray/exports`，可「更改目录」换到任意位置（如网盘同步目录），更改后点底部「保存设置」生效；「恢复默认」回到 exports。
2. **手动即时备份**：勾选备份内容（默认六项；`.env` 含 API Key 谨慎勾选），可开启 **密码加密（AES-256）**——恢复时必须输入同一密码。三个动作：
   - **立即备份**：写入备份存储目录
   - **另存为…**：原生对话框选任意位置保存
   - **仅打包归档**：只打包任务归档目录
3. **自动周期备份策略**：开启后按设定频率（每天 / 每 3 天 / 每周）在指定时刻自动全量备份（**明文不加密**），到点未开机会在下次启动后补跑；「保留份数」自动轮转，**只清理自动备份自身**（`zentray-auto-*`），不动手动导出。
4. **从备份文件恢复**：「选择文件」或手输本机 zip 路径 → 恢复（**替换模式**，覆盖本地所选数据；操作前自动写入安全备份）。加密包需输入密码；密码错误会明确提示。
5. **历史备份快照**：备份目录内所有 zip 列表（文件名/大小/时间/类型/是否加密），支持恢复、删除、刷新。

> 加密备份为 AES-256 zip：恢复请用本应用；系统自带 unzip 可能不支持 AES，第三方解压请用 7-Zip。

重装一般不删用户数据；跨设备迁移用「手动即时备份 + 从备份文件恢复」即可。
用户插件目录（`plugins/`）为备份可选项，需要时在「手动即时备份」勾选；`ops_runs/` 运行日志不在备份范围。

## 8. 故障排查

| 问题 | 处理 |
|------|------|
| 以为没启动 | 查顶栏/托盘与 `zentray.log` |
| 高优先饼图有绿点 | 已修复；可删 `icons/.pie_icons_version` 后重启重生图标 |
| 番茄不像番茄 | 同上重生 `tomato_*.png`；确认在专注状态 |
| 设置页是旧的 | 确认已 `npm run build` 且未设 `ZENTRAY_UI=qt` |
| 无顶栏文字 | Linux 安装 AppIndicator 支持 |
| 每日计划/复盘没到点 | 确认已启用且 API Key 有效；看日志「触发每日计划/复盘」；过点会补跑；改时刻后需等新时间 |
| 计划只在约 8 点跑 | 旧版仅匹配整点小时且内存记「今日已跑」；升级后确认设置里的调度时间已保存 |

```bash
# 强制重生托盘图标
rm -f ~/.local/share/ZenTray/icons/.pie_icons_version
# 然后重启 zentray
```
