# ZenTray macOS 版交互与呈现设计（v1.0 草案）

> 基于 Linux 现网全部功能（v0.7.1：任务轮播+饼图、番茄钟体系、AI 计划/复盘+场景能力、
> 插件体系、双通知渠道、报告托盘轮播、备份、浅色双皮肤）做 macOS 平台移植的**逐页面、
> 逐按钮、逐交互**设计。配套原型图：`.superpowers/prototypes/mac-prototype.html`（浏览器打开）。

---

## 0. 结论速览

| Linux 现状 | macOS 对应 | 关键差异 |
|---|---|---|
| AppIndicator 顶栏 icon+文字 | **NSStatusItem**（菜单栏 extra） | 系统原生支持标题文字；icon 必须 **template image**（单色自适应深浅菜单栏）；⌘拖拽重排系统自带 |
| 右键/左键弹菜单 | **单击即弹 NSMenu** | mac 无左键悬停概念；菜单即点即开即关 |
| 应用弹窗（自绘 Qt 窗） | **UNUserNotificationCenter 系统通知** | mac 上「应用弹窗」渠道改走系统横幅，点击开报告；不再自绘浮窗 |
| Ctrl+Alt+T 闪电添加 | **⌥Space（默认，可改）** | Carbon RegisterEventHotKey；Ctrl+Alt+T 在 mac 无惯例 |
| 空白拖拽+不回弹 | **原生标题栏拖拽** | 移除自研拖拽层；mac 窗口天然不回弹 |
| notify-send 点击动作 | UNNotification click delegate | 同能力：点击开 html/md 报告 |
| .desktop 自启 | **登录项（SMAppService）** | 设置页放「在登录项设置中打开」按钮 |
| 主窗口退出语义 | **LSUIElement=1**（无 Dock 图标、无主菜单栏） | 关窗≠退出不变；退出走菜单项（无 ⌘Q，agent 应用不装主菜单栏） |
| Qt/QWebEngineView 对话框 | 保留（Qt 6 支持 mac） | 呈现层做 mac 化：红绿灯、esc、⌘W、vibrancy 侧栏 |
| 浅色双皮肤 Neo/Aurora | 保留 + **跟随系统外观** | 系统深→深色皮肤；浅→所选浅色皮肤；菜单栏 template 自适应 |

## 1. 平台调研要点（为什么这样设计）

1. **菜单栏 extra（NSStatusItem）**：mac 唯一合法常驻入口。标题文字（`button.title`）为系统
   13pt，与系统时钟同高对齐——Linux 的「饼图+标题轮播」形态可 1:1 保留。icon 用
   `image.template = true`，系统自动适配浅/深菜单栏与 hover；饼图的三色语义在 template 下
   退化为单色剪影 → **决策：icon 保持彩色非 template（NSStatusItem 允许彩色），仅休息段/
   空闲饼图提供单色变体**；彩色 icon 需同时提供浅色菜单栏下的描边版本（2 套 png，按
   `NSAppearance` 切换）。Retina 需 @1x/@2x 两套。
2. **NSMenu**：macOS 13+ 支持 section 分组与缩进子菜单；单击弹菜单；菜单在状态切换时
   `popUpMenu:` 之外不可编程保持。菜单项支持快捷键标注（仅窗口聚焦时生效，agent 应用
   基本无效 → 菜单内**不标快捷键**，动作直达）。
3. **通知（UNUserNotificationCenter）**：需首次请求授权（alert+badge+sound）；用户拒了则
   「应用弹窗」渠道静默降级（同 Linux notify-send 不可用行为）。横幅点击 → delegate
   回调 → 开报告（html→默认浏览器，md→默认编辑器/预览）。通知内容支持 title/body，
   长报告摘要截断到 body 上限。**通知样式（横幅/提醒）归系统设置管**，文档引导用户设
   「横幅+显示预览」。
4. **全局热键**：Carbon `RegisterEventHotKey` 仍是事实标准（NSEvent globalMonitor 拿不到
   键盘除非辅助功能授权）。默认 ⌥Space，与 Spotlight（⌘Space）错开；冲突时引导改键。
5. **登录项**：macOS 13+ `SMAppService.mainApp.register()`；卸载自动注销。
6. **窗口材质**：`NSVisualEffectView`（sidebar 毛玻璃）在 Qt 下用 `QtMacExtras` 时代已废，
   Qt 6.6+ 有 `QWindow`-级 `windowMaterial` 近似；**务实决策：Vue 内用 CSS 半透明白/黑 +
   `backdrop-filter` 模拟 vibrancy**，不动 native 层——与现有 Aurora 玻璃风格天然一致。
7. **打包公证**：分发 dmg 需 Developer ID 签名 + notarize（xcrun notarytool），否则用户首启
   要右键打开。本地自用可 ad-hoc 签名跳过。

## 2. 全局交互决策（差异映射表）

| 交互 | Linux 行为 | mac 行为 |
|---|---|---|
| 弹菜单 | 左/右键 | **单击** |
| 打开设置 | 菜单「设置」 | 菜单「设置…」+ 任何 ZenTray 窗口内 **⌘,**（mac 惯例） |
| 关闭窗口 | × / Esc | **红灯 / Esc / ⌘W**（三等效） |
| 移动窗口 | 空白拖拽（自研） | 标题栏/工具栏拖拽（原生）；移除自研拖拽层 |
| 上下文菜单 | 右键 | 右键 / **⌃单击**（触控板用户） |
| 数值调节 | ▲▼ 按钮 | ▲▼ + **双指滚动**（触控板悬停滚调） |
| 列表滚动 | Qt 滚动条 | 原生 rubber-band + 触控板惯性 |
| 多选确认 | Ctrl+点击 | **⌘点击** |
| 全选 | Ctrl+A | ⌘A（表单内） |
| 通知点击 | notify-send action | 横幅整体点击 |
| 托盘图标重排 | 不支持 | **⌘拖拽**（系统） |
| 状态文字 Tooltip | 无 | 菜单栏 icon 悬停 1s 显示全量状态（当前任务全名+进度+番茄态） |

## 3. 菜单栏（NSStatusItem）逐状态

位置：屏幕右上角，系统图标（Wi-Fi/电池）左侧，⌘可拖。宽度自适应标题。

**构成**：`[饼图icon 18×18pt(@2x)] [标题文字 系统字体13pt]`，间距 4pt。

| 状态 | icon | 标题文字 | 点击菜单首行 |
|---|---|---|---|
| 启动加载 | 单色 app 剪影 | 无文字 | 「加载中…」（禁用项） |
| 任务轮播 | 优先级饼图（红/黄/绿+填充） | 任务标题（截 48 字符），逾期带前缀，分类带 `[一级-二级]` | 🍅 融合按钮 |
| 报告待查看（轮播交替） | app icon（彩色小稿） | `📄 插件报告待查看: <名>` / `📄 计划报告待查看` | 同上；点开报告即退出轮播 |
| 脚本运行 | app icon | `⚡ <插件名> 运行中…`（暂替轮播） | 运行中状态项 |
| 番茄-专注 | 番茄饼图（红果+绿萼+填充） | `25:00 · <任务标题>` 或自定义文案（+任务后缀） | 进行中控制区 |
| 番茄-短休/长休 | 茶绿圆饼 | `休息 4:32`（恒倒计时） | 进行中控制区 |

轮播节奏沿用设置（各优先级秒数/模式）；报告轮播与任务**交替**，不占脚本/番茄优先级。

## 4. 菜单（NSMenu）逐项设计

结构：状态区（section）→ 分隔 → 动作区（section）→ 分隔 → 系统区。无快捷键标注。

**空闲态（默认）**：
```
────────────────────────────
 🍅 专注 25mins · 今日 75mins      ← 融合按钮；点击=以默认时长开始未绑定专注
    （格式来自设置 menu_label_format：{focus}/{today}/{count} 占位）
────────────────────────────
 📋 任务列表                        ← 打开任务窗口（单活：已开则前置）
 ⚡ 快速添加…                       ← 打开快速添加面板
 🧩 插件                            ← 打开插件面板
────────────────────────────
 📜 历史…
 ⚙️ 设置…
────────────────────────────
 退出 ZenTray
```

**专注中**：
```
────────────────────────────
 🍅 专注中 · <任务标题或「自由专注」>
 ⏱ 14:32 剩余 · 今日 🍅 3 · 75 分钟   ← 只读状态行（禁用项）
────────────────────────────
 ⏭ 跳过休息（进入休息后显示「⏭ 跳过休息」→ 休息中显示「▶ 开始下一段专注」）
 ➕ 延长 5 分钟
 ⏹ 中止专注（≥1 分钟记入历史）
────────────────────────────
（动作区/系统区同空闲）
```

**休息中**：状态行「☕ 短休 · 4:32 剩余」；控制区「▶ 开始下一段专注」「⏹ 结束休息」。

**脚本运行中**：状态行「⚡ <插件> 运行中…」；「⏹ 停止脚本」；番茄启动项禁用（双向拦截）。

**无任务**：融合按钮下加禁用行「暂无活跃任务」；轮播标题空。

## 5. 任务列表窗口

窗口：**908×640**（内容最小 760×560，可缩放），打开居中，红绿灯置顶左。标题栏合并工具栏
（mac 惯例）：左三灯，右侧「＋ 新建」胶囊按钮（主色）。⌘N 新建、⌘F 聚焦筛选。

布局三段：顶部分段控件（活跃 / 周期 / 历史）+ 搜索框；左列任务卡列表（滚动）；右列详情卡。

**分段控件（三视图）**：
- 活跃：按优先级分组；卡片 = 饼图缩略 + 标题 + `[分类]` 标签 + 截止 + 子任务进度条（10% 步进色条）。
- 周期：模板卡（日/周/月徽标 + 派发时间 + 预设子任务数）。
- 历史：日期归档列表，只读。
- 点选卡片 → 右侧详情；⌘点击多选不提供（详情是单卡模型）。

**搜索框**：实时过滤标题/分类/备注；Esc 清空。

**任务卡（逐交互）**：
- 单击：选中，详情卡切换（左列选中态=主色 8% 洗底+2px 左缘条）。
- 双击标题：等价「编辑」。
- 右键/⌃单击：上下文菜单「编辑 / 完成 / 废弃 / 🍅 以此任务专注 / ▶ 运行关联插件」。
- 悬停卡片右上角出现快捷「✓」完成按钮（单击完成任务，含确认）。

**详情卡（右列，逐按钮）**：
- 头部：标题（多行）+ 分类标签 + 优先级色点 + 截止；逾期红字前缀。
- 子任务区：逐条复选框（点击切换完成，划线动画）；行悬停出现「×」废弃；底部输入框「添加子任务，回车确认」。
- 进度条：子任务自动汇总；仅展示不可拖（数据源是子任务）。
- 操作行（按序）：`编辑`（弹编辑 sheet）/ `✓ 完成`（主色）/ `废弃`（灰）；`🍅 专注`（实心主色，等价菜单以该任务启动）。
- 「▶ 运行关联插件」：有关联插件时显示；运行带任务上下文。
- 「AI 建议」卡（开启场景能力时）：右卡顶部展开；建议条目分两类——带「应用」按钮（提级/改截止/追加子任务，点击即生效并刷新）与纯文本（仅展示+「忽略」逐条消掉）。

**新建/编辑（sheet 从属窗口，mac 惯例 sheet 而非新窗）**：
- 字段：标题（多行）、分类二级联动下拉、优先级分段、截止（mac 原生日期时间选择器样式）、
  提醒开关+时间（周度直接选周几+时分，分段式数字输入，输满自动右移）、关联插件下拉+「试运行」、备注。
- 「📷 图片识别」按钮：NSOpenPanel 选图 or **⌘V 粘贴截图**；多条先选一条再进草稿。
- 「✨ 智能解析」按钮：标题/备注一句话 → 草稿预览（逐字段确认）→「应用到表单」回填。
- 底部：「取消」（Esc）/「保存」（⌘↩）；保存时弹窗提醒冲突检测（与其它任务/AI 调度时刻），「仍要保存」确认。

## 6. 快速添加（Spotlight 风格）

触发：⌥Space（全局热键，可改键）。无任务窗口也可用（agent 应用热键独立于窗口）。

面板：**640×动态**，屏幕水平居中、垂直 38% 处；出现动画 120ms 缩放 0.96→1+淡入（对齐
Spotlight 肌肉记忆）。毛玻璃材质（CSS backdrop-filter）。

- 大输入框占满宽度；placeholder「记一笔，回车保存…」。
- 输入即解析预览行：识别到的截止/分类即时以灰色小标签显示在输入框下方。
- 「✨」按钮（输入非空时点亮）：AI 解析 → 面板向下展开草稿卡（标题/分类/优先级/截止/子任务
  逐项），「确认添加」入任务库，「返回编辑」回到纯文本。
- `↩` 保存并清空（toast「已添加」0.8s）；`Esc` 关闭；`⇥` 焦点到分类快速选择。
- 保存后面板保持打开（连续记事），`Esc` 或点面板外关闭。

## 7. 设置窗口

窗口 **880×620**，可缩放（最小 720×520）。**⌘,** 全局打开。左导航 220px 毛玻璃侧栏
（mac「设置」App 同构：侧栏图标+文字，选中=主色洗底），右侧内容区滚动。

侧栏（自上而下）：✨ AI 能力 / 🔔 通知 / 📋 任务 / 🍅 番茄钟 / 🧩 插件 / 🖥️ 系统 / 💾 备份 / 📜 历史。

各页逐控件（与 Linux 功能对齐，仅列 mac 呈现差异）：

**✨ AI 能力**：顶部场景开关卡（智能解析/图片识别/任务建议，默认关）；下方标签页「每日计划 /
每日复盘 / 模型接入」。JobEditor 逐控件：启用开关；时间选择（分段数字，输满右移）；跳过公休日
开关；保存到本地开关；**完成通知渠道**复选组（应用弹窗/WxPusher，至少留一，空=全选）；
**报告托盘轮播**（开关+分钟数字，双指滚动可调）；风格区（毒舌/温柔/干练+自定义，提示词可编辑）。
模型接入：多 API 折叠行（名称/key/BaseUrl/模型），同时仅一个启用；key 输入为密码框（⌘⌥显
示明文——mac 密码框惯例）。

**🔔 通知**：应用弹窗行（mac 上=系统通知；子行「在系统设置中配置横幅样式…」跳转
`x-apple.systempreferences:com.apple.Notifications-Settings`）；WxPusher 行（展开配 token/uid）。

**📋 任务**：各优先级停留秒数、轮播模式；逾期前缀与开关；分类管理（括号/分隔符/二级开关/
一二级增删改，行内编辑）。

**🍅 番茄钟**：节奏预设三卡（经典 25/5、深度 50/10、超长 90/20，点击选中）；时长组（专注/短休/
长休/长休间隔，数字框）；延长分钟；自动休息/自动专注开关；每日目标；托盘右侧显示（倒计时/文案
分段）；菜单按钮融合文案输入框（占位符 {focus}/{today}/{count}，下方实时预览一行）。

**🧩 插件**：总开关卡（含**运行报告托盘轮播**开关+分钟、**脚本完成通知渠道**复选组）；三大折叠块
——📜 插件列表（默认展开：排序、逐插件展开调度规则/参数预设、授权开关、运行、编辑/删除/说明；
variadic 参数「＋ 加一条」增行、行内删除、至少一行）；📦 导入插件（默认收起，zip/目录，
先预览校验再安装，同名询问覆盖）；🗂 运行历史（运行ID/起止/结果/摘要，点行日志抽屉，行内
「报告」系统应用打开）。

**🖥️ 系统**：外观（**跟随系统 / 浅色 / 深色**三选一 + 浅色下 Neo 纸墨 / Aurora 冰璃 双皮肤卡；
深色单皮肤）；动效开关；形状风格；**登录项**：开关（SMAppService 注册/注销）+「在系统设置中
打开…」按钮。

**💾 备份**：五卡片——存储目录（「更改…」NSOpenPanel+安全书签、「在 Finder 中显示」、恢复默认）；
手动备份（六项勾选、AES-256 密码输入（mac 密码框样式）、立即备份/另存为…/仅打包归档）；
自动周期（频率+时刻+保留份数）；从备份文件恢复（选择文件/手输路径+密码域）；历史快照列表
（恢复/删除/刷新，行内尺寸与加密徽标）。

**📜 历史**：只读单页，日期侧栏+合并时间轴+详情。

底部全局：「保存设置」主按钮（有未保存变更时脉冲提示）+「还原未保存项」。

## 8. 插件面板窗口

**600×540** 固定（对齐现网缩小后尺寸），不可缩放（工具面板惯例），红绿灯+标题「插件」。

双标签（分段式）：
- **插件**：顶部分类 chips（单选，全部分类默认）+ 类型下拉（全部/脚本/服务）；纵向卡片列表。
  卡头：名称 + 类型徽标（脚本绿/服务红）+ 分类徽标 + 右侧按钮组——`▶ 运行`/`▶ 启动`
  （实心主色、独立显眼）、`说明`/`报告`/`日志`（文字钮）。卡头单击展开参数表单（手风琴，
  展开一张收起其余）；参数行=名称+输入框（回车即运行）；variadic 参数「＋ 加一条」增行。
  服务卡已运行时「▶ 启动」变「↗ 跳转已开服务」（不重复开标签）。刷新/筛选/切标签自动收起。
  窗口重获焦点自动刷新（1s 节流，编辑中跳过）。
- **记录**：插件过滤下拉+历史表（运行ID/插件/触发/开始/结果/摘要）；点行开执行报告抽屉
  （状态/起止/耗时/触发/关联任务/摘要/结果正文/完整日志）。

## 9. 通知（mac 呈现）

- 形态：系统横幅（右上角滑入，5s 自动收进通知中心）；标题=「ZenTray」来源，正文=具体标题。
- **点击横幅**：打开对应报告（html→默认浏览器；md→默认阅读器）；AI 计划/复盘点击同。
- 通知中心：按 ZenTray 分组堆叠；「报告待查看」轮播与通知独立（点了通知=已查看，轮播退出）。
- 首次触发通知前弹系统授权（alert）；拒绝后设置-通知页显示黄条引导重开。
- WxPusher 渠道不变（与系统通知并行，渠道多选控制各入口）。

## 12. 技术落点（给实现者）

1. `zentray/ui/tray.py` 新增 `MacStatusItemTray(TrayImplementation)`：PyObjC 包 NSStatusItem
   + NSMenu + UNUserNotificationCenter（现 Linux 桥接进程模式不需要——PyObjC 可同进程）。
2. Vue 对话框层 Qt/PySide6 mac 直跑，`web_host.py` 窗口旗标加 mac 分支（红绿灯默认即有；
   移除 Linux 自研拖拽注入）。
3. 热键 worker：Carbon RegisterEventHotKey（PyObjC）。
4. 登录项：SMAppService（macOS13+），旧系统回退 launchctl plist。
5. 打包：`scripts/build_package.sh` 增加 mac 分支 → py2app 或 PyInstaller + create-dmg +
   notarytool 公证。
6. 风险：菜单栏空间不足时 mac 自动隐藏 extra 标题（系统行为，无解，文档说明）；通知授权
   拒绝的降级路径必须有。
