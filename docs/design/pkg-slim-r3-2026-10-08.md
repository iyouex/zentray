   vncdotool 本身 0 命中于 Analysis TOC）。运行时从不触发该路径，excludes 零风险。
   Cryptodome（2M）保留——pyzipper 备份 AES 真实消费者。

## 剩余空间与天花板（下轮决策项，非本轮）

非 WebEngine 部分已基本榨干（Qt so 均 stripped、deb xz -9、碎 lib 各有消费者）。
唯一大项仍是 **libQt6WebEngineCore 195M + Quick/Qml 栈 ~30M + icudtl 10M**：

docs/design/retrospective-redesign-2026-10-08.md（该报告 D1 建议删 Qt 回退 UI，可与此合并评估）。
