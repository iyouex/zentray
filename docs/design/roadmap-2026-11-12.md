## P2 功能扩展（0.8.x，用户已全选）

| # | 主题 | 要点 |
|---|------|------|
| A | 智能清单+搜索 | TaskList 快捷筛选（今天/逾期/本周到期/无截止）+ 标题/详情全局搜索 |
| B | 统计回顾 | 周/月完成量、番茄分布、逾期率视图；输出可喂暮省上下文 |
| C | 多设备同步 | WebDAV/坚果云自动备份同步（复用备份恢复，重点在调度与冲突处理） |
| D | 插件生态 | 独立 zentray-plugins 合集仓库 + URL 一键安装 |

顺序建议 A → B → C → D（A/B 共享 TaskList/History 数据层可同批；C 涉及网络与冲突最重；D 依赖仓库基建）。
