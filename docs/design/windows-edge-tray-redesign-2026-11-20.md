---

## 0. 一句话

把托盘从任务栏里解放出来：**悬浮在桌面之上，但永远紧贴屏幕四条边**——像一块从边缘长出来的玻璃。
收起时只占一条边，展开时朝屏幕内侧生长；不占任务栏、不抢焦点、不挡内容。

---

## 1. 为什么要重做

现行 Windows 方案是 2026-10-17 的 **AppBar 任务栏状态条**：在任务栏正上方用系统级 AppBar 保留一条 ~30px 的常驻条带。它的优点是“完整标题不截断”，但问题也很明显：

1. **系统级占位**：AppBar 会永久占用 30px 桌面高度，最大化窗口必须避让，用户没有“今天不想看见它”的轻量选择。
2. **位置被任务栏锁死**：只能在底部；多显示器、竖屏、任务栏换边时体验不一致。
3. **观感偏“系统组件”**：它看起来像第二条任务栏，而不是 ZenTray 自己的界面。
4. **实现重**：`SHAppBarMessage` 注册/仲裁、`ABN_FULLSCREENAPP`、Explorer 重启重登记，边界情况多。

“贴边悬浮托盘”保留“常驻可瞥一眼”的核心价值，同时把**位置、形态、显隐**全部交还给用户：它可以停在任意一条边，可以缩成一条耳，也可以在你看全屏时自动消失。

## 2. 四条设计原则

| # | 原则 | 含义 |
|---|---|---|
| 01 | **永远贴边** | 拖动只在上下左右四条边之间迁移；松手后磁吸归位。不允许停在桌面中央。 |
| 02 | **从边缘向内生长** | 收起是贴边的“耳/胶囊”，展开朝屏幕内侧长出面板；外侧始终平直贴边。 |
| 03 | **一眼，不打扰** | 常驻只保留：当前任务、子任务进度环、番茄倒计时；其余悬停/点击后出现。 |
| 04 | **零焦点成本** | 不激活窗口、不进 Alt-Tab、不改变前台应用；全屏自动隐藏，退出恢复。 |

**“贴边”的基准**：贴的是**可用桌面边界**。任务栏所在的那条边，胶囊贴任务栏上缘（不遮挡时钟、通知区与任务栏图标）；其余三边贴物理屏幕边缘。任务栏自动隐藏时贴屏幕底边，任务栏弹出时自动上移。

## 3. 三个方向（原型已出图）

### 方向 A · 贴边胶囊（推荐）

- **收起**：392×54 横向胶囊（竖向 54×348），外侧平直、内侧 18px 圆角；进度环 + 标题 + 子任务/截止 + 番茄倒计时。
- **展开**：424×~330，底边贴边、向上生长；当前任务卡 + 子任务进度 + 番茄控制 + 报告 chip + 4 个快捷动作。
- **收纳**：闲置 8s 且鼠标离开 → 168×44 边缘耳（进度环 + 倒计时），悬停恢复。
- **气质**：工具感、克制、信息密度刚好；最适合作为主力日常形态。

### 方向 B · 桌面灵动岛

- **收起**：356×46 顶部“刘海”，通体近黑玻璃，标题 + 倒计时 + 状态点。
- **展开**：470×auto，形变展开；大号 NOW、事件条、动作行、任务轮播点。
- **事件态**：报告完成 / 番茄结束 → 短暂“弹”出一条事件胶囊，3s 后缩回。这是普通托盘图标做不到的行为反馈。
- **风险**：顶部最大化窗口会持续压住标题栏；更适合作为“顶部停靠”的形态或 A 的事件补充，而不是唯一默认位置。

### 方向 C · 边缘抽屉

- **收起**：34×136 边缘耳，只留进度环 + 剩余分钟 + 抓握纹。
- **展开**：372×470 抽屉，从边缘滑出；当前任务 + 番茄 + **接下来 3 条** + 待看报告 + 底部动作。
- **气质**：存在感最低、打扰最少；适合把 ZenTray 当后台计时器的人。
- **代价**：常驻看不到任务标题，日常“瞥一眼”的能力弱于 A。

### 取舍

| 维度 | A · 贴边胶囊 | B · 桌面灵动岛 | C · 边缘抽屉 |
|---|---|---|---|
| 收起形态 | 392×54 / 54×348 | 356×46 刘海 | 34×136 边缘耳 |
| 常驻信息 | 标题 + 进度 + 倒计时 | 标题 + 倒计时 + 事件 | 仅进度 + 分钟 |
| 展开内容 | 任务 + 番茄 + 报告 + 4 动作 | 大号 NOW + 事件 + 动作 | 今日控制台（含下 3 条） |
| 视觉存在感 | 中 | 高 | 低 |
| 遮挡风险 | 低（可收纳） | 中 | 最低 |
| 实现复杂度 | 中 | 高 | 中 |
| 最适合 | 主力日常 | 强反馈 / 演示型 | 极简 / 免打扰 |

**推荐组合**：以 **A 为骨架**，吸收 **B 的事件态**（报告完成/番茄结束短暂变形 3s）与 **C 的收纳态**（闲置缩成边缘耳）。
默认形态 A；B 的“顶部灵动岛”和 C 的“极简耳”作为设置里的形态选项（v0.9 再开）。

## 4. 方向 A 规格（推荐方案）

### 4.1 几何

| 部位 | 收起（横） | 收起（竖） | 展开 |
|---|---|---|---|
| 尺寸 | 392×54 | 54×348 | 424×~330（内容自适应） |
| 贴边侧 | 平直（0 圆角） | 平直 | 平直 |
| 内侧 | 18px 圆角 | 18px 圆角 | 18px 圆角 |
| 内边距 | 0 13px | 14px 0 | 0 0 12px |
| 进度环 | 30px（内孔 4px） | 30px | 46px |
| 标题 | 13.5px / 620 | 竖排 12px / 1.35 | 15px / 650 |
| 计时 | 12.5px 等宽 | 10.5px 等宽 | 23px 等宽 |

- 底部停靠：`bottom = 任务栏高度`（工作区底边），底边与任务栏上缘严格对齐；底部 1px 强调内发丝线。默认沿边位置 **75%（偏右，贴近原通知区）**；原型截图居中仅为展示对称形态。
- 顶部停靠：`top = 0`，向下生长；顶部 1px 内高光。
- 左右停靠：`left/right = 0`，横向 54px；标题用 `writing-mode: vertical-rl`（中文竖排天然可读）；展开朝屏幕内侧。

### 4.2 三态

| 状态 | 触发 | 行为 |
|---|---|---|
| 常驻 | 默认 | 392×54；番茄进行中始终显示倒计时 |
| 收纳 | 无交互 8s 且鼠标离开 | 缩成 168×44 边缘耳；悬停 120ms 恢复 |
| 展开 | 悬停 180ms / 单击 | 424×~330；点击面板外或 Esc 收起 |
| 固定 | 展开后单击 | 钉住，直到再次点击/Esc；拖走即取消 |
| 事件 | 报告完成 / 番茄结束 | 在胶囊上方弹出一条 3s 事件条（借 B 的事件态） |

- 悬停只“预览”，点击才“固定”，避免鼠标路过边缘时被面板挡住。
- 展开期间胶囊本体变成面板的“边缘轨”，不重复显示。
- 面板内容复用现有 `/glance` 数据：当前任务、子任务、番茄、报告 chips、快捷动作。

### 4.3 视觉

- 深色：`linear-gradient(180deg, rgba(44,49,61,.92), rgba(22,25,32,.97))` + 1px 内高光；浅色跟随系统（白玻璃 + 冷灰描边）。
- 强调色：Windows 系统 accent（默认 `#4cc2ff` 深色 / `#0078d4` 浅色）；优先级高/中/低 `#ff6b6b / #ffc44d / #4ade80`。
- 阴影只朝屏幕内侧投射，外侧贴边不投影；圆角与 1px 发丝线按 DPR 绘制。
- 动效：吸附 220ms `cubic-bezier(.2,.85,.2,1)`；展开 180ms 淡入 + 8px 位移；收纳 160ms 缩放。全部尊重系统“减少动态效果”。

## 5. 交互规则

### 5.1 拖动与吸附

- **把手**：胶囊空白区 / 面板顶部 26px 抓握条。按钮、计时 chip、报告 chip 不触发拖动。
- **吸附**：释放点距任一边 ≤ 56px 即吸附；否则 220ms 弹回上一条边。**不允许停在桌面中间**。
- **沿边位置**：底部/顶部记横向 0–100%，左/右记纵向 0–100%；默认 75%（偏右）；可拖到任意位置并记忆。
- **边缘提示**：拖动时四条边出现 9px 发光带 + 虚线展开区，指示“会从哪边展开”。
- **记忆**：每台显示器独立记忆「边 + 沿边位置」；显示器拔插回落到主屏。

### 5.2 焦点与全屏

- `Qt.Tool | FramelessWindowHint | WindowStaysOnTopHint` + `WA_TranslucentBackground` + `WA_ShowWithoutActivating`。
- Win32 追加 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`：不抢焦点、不进 Alt-Tab。
- 显式呼出（点击通知区图标 / 可选热键）才允许聚焦。
- `SHQueryUserNotificationState` 为 `QUNS_RUNNING_D3D_FULL_SCREEN` / `QUNS_PRESENTATION_MODE` 时隐藏；退出后回到原边原位。500ms 轮询，开销可忽略。
- 可选「专注时也隐藏」；默认关闭。

### 5.3 任务栏与通知区

- **保留通知区图标**：toast 身份、右键菜单、退出兜底；左键点击图标 = 呼出托盘。
- 底部停靠时贴任务栏上缘，不遮挡时钟/通知区/任务栏图标。
- 任务栏自动隐藏：贴屏幕底边；任务栏弹出时自动上移。
- 退出仍走右键菜单「退出」；关闭任务列表/设置窗口 = 隐藏，不退出。

### 5.4 键盘

- `Ctrl+Alt+T` 快速添加保持不变。
- 可选呼出热键：默认**关闭**；开启后建议 `Ctrl+Alt+Space`（避免与 `Win+Shift+Z` 等系统键冲突）。
- `Esc` 收起展开面板；面板内 `Tab` 焦点顺序按“当前任务 → 番茄 → 报告 → 动作”。

### 5.5 多显示器与 DPI

- 布局用逻辑像素；1px 线、圆角、阴影按 `devicePixelRatio` 绘制。
- 跨 125% / 150% / 200% 缩放不糊；切换显示器后重新计算贴边矩形。
- 仅主屏默认显示；可在设置里开关“所有显示器各显示一个”。

## 6. 实现映射

| 层 | 方案 |
|---|---|
| 胶囊本体 | **原生 QWidget + QPainter**：圆角、玻璃底、进度环、阴影自绘；闲置时几乎零 CPU。 |
| 展开面板 | 复用现有 Vue `/glance`（`web/src/views/Glance.vue`）装在**透明 QWebEngineView** 里；展开显示、收起隐藏。 |
| 窗口 | `FramelessWindowHint | Tool | WindowStaysOnTopHint` + `WA_TranslucentBackground` + `WA_ShowWithoutActivating`；Win32 `WS_EX_NOACTIVATE`。 |
| 贴边状态机 | 新 `EdgeDock`（`edge: top/bottom/left/right` + `ratio: 0..1`）；横/竖两套 QLayout；展开方向由 edge 决定。 |
| 全屏 | `ctypes` 调 `shell32.SHQueryUserNotificationState`，500ms 轮询；不引入 `pywin32` 新依赖。 |
| 替代 | 退役 `WindowsStatusStripTray`（AppBar）；保留 `WindowsTray`（通知区）。 |
| 改动文件 | `zentray/ui/win_edge_tray.py`（新 `WindowsEdgeTray` / `_CapsuleWindow` / `_DragOverlay`）、`zentray/ui/edge_dock.py`（纯几何/停靠状态机）、`tray.py`（工厂优先 EdgeTray → AppBar → WindowsTray）、`win_tray.py`（旧 AppBar 保留回退）、`web_host.py` / `Glance.vue`（P2）、设置页（P2/P4）。 |
| 记忆项 | `win_tray.edge` / `win_tray.ratio` / `win_tray.monitor` / `win_tray.form`（capsule/island/ear）/ `win_tray.hide_fullscreen` / `win_tray.hover_expand_ms`。 |

## 6A. 细化交互（2026-11-20 追加）

原型新增「交互细化」节，锁定每条边的职责与手势。

### 6A.1 边的命名

| 名称 | 位置 | 职责 |
|---|---|---|
| 宽边（spine） | 贴屏幕的那条长边 | 悬停=曲边箭头；单击=任务详情 + 下一步；长按 400ms=拖动 |
| 窄边 A（内容端） | 上/下边停驻=左端；左/右边停驻=上端 | 悬停/单击=插件 / 任务列表 |
| 窄边 B（系统端） | 上/下边停驻=右端；左/右边停驻=下端 | 悬停/单击=设置 / 退出 |

- 标题始终靠近宽边；宽边热区是整条长边（约 18px 带），不是只有箭头本身。
- 左右边停驻时标题竖排，宽边/窄边的语义不变。

### 6A.2 宽边手势

| 手势 | 反馈 | 结果 |
|---|---|---|
| 悬停 180ms | 两条曲边箭头从两端滑入，在标题下方聚拢；宽边出现 1px 强调线 | 提示“可点” |
| 单击 | 箭头收拢，详情从宽边向内生长（180ms） | 任务详情 + 下一步操作提示 |
| 长按 400ms | 指针处出现 400ms 环形进度；满格后胶囊抬起（scale 1.03 + 阴影） | 进入拖动 |
| 长按后移动 | 半透明宽箭头从胶囊指向移动方向，长度展开 180ms | 沿四边拖动 |
| 移动 < 8px 或 < 400ms 松手 | 进度环取消 | 不触发拖动 |

- 单击与长按互斥：按满 400ms 即进入拖动，不再触发详情。
- 拖动只在宽边触发；窄边不参与拖动，避免与侧面板冲突。
- 宽边箭头是“提示层”，点击热区包含箭头所在的内侧 24px，避免必须精准点箭头。

### 6A.3 窄边与面板

| 停驻 | 窄边 A（内容端） | 窄边 B（系统端） |
|---|---|---|
| 上 / 下边 | 左窄边 → 插件 / 任务列表，向左滑出 | 右窄边 → 设置 / 退出，向右滑出 |
| 左 / 右边 | 上窄边 → 插件 / 任务列表，向上滑出 | 下窄边 → 设置 / 退出，向下滑出 |

- 窄边箭头与宽边同款曲边箭头，方向沿边向外；悬停 120ms 出现，点击即滑出。
- 插件/任务列表面板：360×430，顶部「任务 / 插件」分段 + 搜索；任务区当前 + 下 3 条；插件区 3 行带运行按钮；底部「打开完整列表」。
- 设置/退出菜单：236×auto，设置 / 插件管理 / 通知与专注 / 快捷键 / 退出。
- 面板与胶囊共用同一条贴边：底部停驻时面板底边贴任务栏上缘；左右停驻时面板侧边贴屏幕边。
- 面板打开时胶囊保留为“边缘轨”，再次点击窄边或点击外部关闭。
- 角落无空间时：面板翻转到内侧展开（推荐），不换边、不改变 A/B 语义。

### 6A.4 拖动、8 个停顿点与角落

- **全屏贴边**：拖动时胶囊始终贴在最近的一条边上，不能停在桌面中间；跨过角落自动旋转 90° 到相邻边。
- **8 个磁吸停顿点**：4 个角 + 4 条边的中点；沿边拖动时距停顿点 ≤ 34px 会被吸住（可继续拖过）；松手时距 ≤ 68px 吸附到该点，否则停在当前位置。
- **半透明宽箭头**：拖动方向上的 240×64 宽箭头（透明度 0→55%），从胶囊中心向拖动方向展开 180ms；换向时旋转，过角时沿角弯曲。
- **抬起态**：拖动中胶囊 scale 1.03、阴影加深、边缘 1px 强调描边，明确“已拿起”。
- **角落**：4 个角是共享停顿点；从底边拖到右下角时旋转为竖排，继续沿右边向上；角上也可停驻。
- **全屏让路**：拖动/展开过程中不改变；全屏应用仍按 §5.2 隐藏。

### 6A.5 实现补充

| 项 | 方案 |
|---|---|
| 宽边热区 | 原生窗口内 18px 带 + 内侧 24px 箭头层；命中测试合并 |
| 单击 / 长按 | `QTimer` 400ms；`mouseMove` 超过 8px 取消；`mouseRelease` 在 400ms 内触发详情 |
| 8 停顿点 | 逻辑像素枚举（4 角 + 4 中点）；磁吸 34px、释放 68px；角上按当前边决定朝向 |
| 宽箭头 | QPainter 半透明渐变 + 180ms 展开；拖动方向取最近一次鼠标位移的主轴 |
| 侧面板 | 独立 `Qt.Tool` flyout，锚定胶囊窄边；不激活、不抢焦点；插件/任务列表复用 WebView，设置菜单用原生 QMenu |
| 角落旋转 | 切换 edge 时重排布局 + 180ms 旋转/形变；不用位图旋转，避免高 DPI 发糊 |

### 6A.6 已确认

1. 8 个停顿点：**磁吸可拖过**（34px 吸住、68px 松手吸附）。
2. 窄边面板在角落无横向空间时：**翻到内侧**展开。
3. 长按拖动：**只限宽边**。
4. 宽边箭头：**整条宽边热区**（18px 带 + 内侧 24px 箭头层）。

## 9. 开发决定（2026-11-20 已确认）

1. **方向**：A 贴边胶囊 + B 事件态 + C 收纳态。
2. **默认边**：底部右侧（沿边 75%）。
3. **层级**：始终置顶。
4. **范围**：只重做托盘入口；任务列表/设置窗保留现状。
5. **停顿点**：8 个点磁吸可拖过。
6. **角落面板**：翻到内侧展开。
7. **长按范围**：只限宽边。
8. **底部基准**：贴任务栏上缘，不遮挡时钟/通知区。
9. **宽边热区**：整条贴屏宽边。
10. **窄边分工**：A=插件/任务列表（上/下边=左、左/右边=上）；B=设置/退出（右/下）。

> 完整交互规格见 §6A；开发按 §7 的 P1→P5 推进。
