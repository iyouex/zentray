# ZenTray Windows 版交互与呈现设计（v1.0 草案）

> 基于 Linux 现网全部功能（v0.7.1：任务轮播+饼图、番茄钟体系、AI 计划/复盘+场景能力、
> 插件体系、双通知渠道、报告托盘轮播、备份、浅色双皮肤）做 Windows 10/11 平台移植的
> **逐页面、逐按钮、逐交互**设计。配套原型图：`.superpowers/prototypes/windows-prototype.html`
> （浏览器打开）。与 macOS 版方案（`mac-interaction-design.md`）并列，功能集完全同源。

## 0. 结论速览

| Linux 现状 | Windows 对应 | 关键差异 |
|---|---|---|
| AppIndicator 顶栏 icon+文字轮播 | **任务栏中央应用按钮：动态图标 + 完整文字标签** | 隐藏窗口造任务栏按钮，icon+文字与 Linux 顶栏完全同构；需任务栏「从不合并」（启动检测+设置引导）；通知区图标降为辅助（菜单锚点/toast/兜底）；见 §3.3 |
| 右键/左键都弹菜单 | **左键=速览面板，右键=上下文菜单** | Windows 托盘惯例（OneDrive/DropBox 同型）：单击主界面、右键菜单 |
| 应用弹窗（自绘 Qt 窗） | **系统 Toast（进通知中心）** | `showMessage` 在 Win10/11 自动渲染为 toast；点击=`messageClicked` 开报告；**无需授权**（与 mac 不同） |
| Ctrl+Alt+T 闪电添加 | **保留 Ctrl+Alt+T** | 本就是 Windows 惯例键；`keyboard` 库已跨平台可用 |
| 空白拖拽+不回弹（自研拖拽层） | **原生标题栏拖拽** | Windows 窗口天然可拖不回弹；移除自研拖拽注入 |
| notify-send 点击动作 | Toast 点击（messageClicked） | 同能力：点击开 html/md 报告；通知中心留存可回看 |
| .desktop 自启 | **HKCU Run 注册表** | 免管理员；「任务管理器 → 启动应用」可见可禁用 |
| 主窗口退出语义 | **× = 隐藏到托盘**（不退出） | Windows 托盘应用惯例；退出走右键菜单，首次 × 弹气泡提示「仍在运行」 |
| Qt/QWebEngineView 对话框 | 保留（Qt 6 原生支持 Windows） | 呈现层 Win 化：─ □ × 三键、DWM 深色标题栏跟随主题 |
| 浅色双皮肤 Neo/Aurora | 保留 + **跟随系统外观** | 系统深→深色皮肤；浅→所选浅色皮肤；标题栏 DWM 同步 |
| （搁置分支）任务栏按钮跑马灯 | **复活并升级为主方案**（2026-10-07 重设计） | 产品要求：托盘内容必须在任务栏中央**完整显示**（图标+文字），不能只有饼图；Win11 23H2+ 已恢复「从不合并」选项，文字标签可用；机制回收 `feature/win-tray-title`；见 §3.3 |

## 1. 平台调研要点（为什么这样设计）

1. **通知区（系统托盘）**：Windows 唯一合法常驻入口，右下角；**只放图标，无文字槽位**。
   Win11 默认把新图标收进 `^` 溢出飞出面板——设计必须容忍「藏在溢出里」，并在设置页
   提供「固定到任务栏角」引导（`ms-settings:taskbar`）。图标尺寸随 DPI 16/20/24px，
   需按 devicePixelRatio 绘制避免发糊。
2. **图标动态更换是廉价操作**：QSystemTrayIcon.setIcon 直换 HICON，无 AppIndicator 的
   DBus 往返开销 → **番茄饼图/优先级饼图改为运行时 QPainter 动态绘制**（可画 10% 步进
   填充，还可叠加倒计时数字），替代 Linux 的预烘焙 PNG 序列，更平滑。
3. **左/右键语义分流**：Windows 惯例左键=主界面、右键=菜单（`activated` 信号可精确分流
   Trigger/Context/DoubleClick/MiddleClick）。Linux 版「左右都弹菜单」在 Windows 上会
   被视为反惯例。
4. **Toast 通知**：`QSystemTrayIcon.showMessage` 在 Win10/11 自动升级为 toast——右下角
   滑入、5s 入通知中心（按 ZenTray 分组留存）、**免授权**；「勿扰/专注助手」会静默收藏
   （系统行为，设置页文档说明，报告轮播 chips 兜底）。富 toast（按钮/大图）需 WinRT
   （`winsdk`），**首版不做**：点击开报告已覆盖核心动线。
5. **全局热键**：现网 `keyboard` 库 GlobalHotKeys 在 Windows 原生可用；Ctrl+Alt+T 即
   Windows 惯例（不改键）。若日后换 `RegisterHotKey`（无键盘钩子库依赖），菜单项可
   标注热键——Windows 菜单快捷键标注对全局热键仍有提示意义（与 mac 不同）。
6. **自启**：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写 REG_SZ，免管理员；
   卸载清残留；用户可在任务管理器禁用（设计只读提示，不去对抗）。
7. **窗口材质**：WebView 不透明，Win11 Mica/亚克力无法穿透 → **务实决策：内容区纯色
   皮肤照搬（Neo 纸墨 / Aurora 冰璃），仅原生标题栏走 DWM**
   （`DWMWA_USE_IMMERSIVE_DARK_MODE` 跟随主题深浅；速览面板为原生 QWidget，Win11 22H2+
   可尝试 `DWMWA_SYSTEMBACKDROP_TYPE=Mica`，失败回退纯色，一行 try/except）。
8. **单实例**：现网 QLocalSocket 在 Windows 即命名管道语义，已可用，无需改动。
9. **打包签名**：PyInstaller onedir + Inno Setup 安装器 + zip 便携双发行；未签名首次
   运行 SmartScreen 拦截 → 文档「更多信息 → 仍要运行」（自用可接受；日后买代码签名
   证书再消除）。

## 2. 全局交互决策（差异映射表）

| 交互 | Linux 行为 | Windows 行为 |
|---|---|---|

| 打开设置 | 菜单「设置」 | 菜单「设置」＋任一 ZenTray 窗口内 **Ctrl+,**（可留，非强制惯例） |
| 关闭窗口 | × / Esc | **× / Esc / Alt+F4**（三等效；×=隐藏到托盘，非退出） |
| 移动窗口 | 空白拖拽（自研） | 原生标题栏拖拽；移除自研拖拽层 |
| 上下文菜单 | 右键 | 右键 |
| 数值调节 | ▲▼ 按钮 | ▲▼ + **鼠标滚轮悬停调节**（Windows 数字框惯例） |
| 多选 | Ctrl+点击 | Ctrl+点击；**Shift 范围选**（Windows 惯例补齐） |
| 全选 | Ctrl+A | Ctrl+A（表单内） |
| 通知点击 | notify-send action | toast 整体点击；通知中心条目点击同效 |
| 托盘图标位置 | 顶栏固定 | **任务栏中央按钮**（从不合并时图标+文字）＋通知区辅助图标（可拖动；Win11 默认藏 `^` 溢出） |

| 首次关闭窗口 | 直接关 | × 时气泡提示「ZenTray 仍在后台运行」一次（学习期，此后静默） |

## 3. 任务栏中央按钮 + 速览面板 + 通知区辅助图标（Windows 版「顶栏轮播」的等价物）

### 3.0 主显示：任务栏中央应用按钮（2026-10-07 重设计）

**形态**：任务栏正中（Win11 默认居中对齐）常驻一枚 ZenTray 应用按钮——**动态图标 +
完整文字标签**，与 Linux 顶栏 icon+文字轮播**完全同构**。这是 Windows 版的主显示槽位；
通知区图标（§3.1）降为辅助（菜单锚点 / toast / 合并模式兜底）。

**机制**（回收搁置分支 `feature/win-tray-title` 已验证做法）：
- 1×1 离屏无边框 QWidget（带 `WindowMinimizeButtonHint` 保任务栏分组正确）→
  系统为其生成居中任务栏按钮；
- `setWindowIcon()` = QPainter 运行时绘制（复用 §12-1 的 `icon_paint_spec` /
  `paint_tray_pixmap`，饼图/番茄/茶绿/转圈/徽标/倒计时叠加全部通用）；
- `setWindowTitle()` = 轮播文字（任务标题 / 番茄倒计时 / ⚡ / 📄）；
- `setToolTip()` = 全量状态（≤128 字符）。

**前置条件与引导**：文字标签仅在任务栏「合并任务栏按钮 = 从不」时显示（Win10 默认就
显示标签；Win11 23H2+ 恢复该选项）。启动读
`HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced\TaskbarGlomLevel`
（0=始终合并 1=占满时 2=从不）：
- `=2` → 完整形态（图标+文字）；
- `≠2` → 设置-系统页提示行「任务栏当前合并按钮，文字标签不显示」+「前往任务栏设置」
  按钮（`ms-settings:taskbar`）；图标层兜底不受影响（徽标/倒计时叠加/速览面板照常）。

**按钮逐状态**（图标同 §3.1；下表为标签文案）：

| 状态 | 按钮图标 | 按钮文字标签 |
|---|---|---|
| 启动加载 | 单色剪影 | `ZenTray` |
| 任务轮播 | 优先级饼图 | `[工作-需求B] 编写交互设计文档`（≤20 字超长截断…，可选跑马灯） |
| 报告待查看 | app icon+红点徽标 | `📄 插件报告待查看: <名>`（与任务槽交替轮换，同 Linux） |
| 脚本运行 | app icon+转圈弧 | `⚡ <插件名> 运行中…`（抢占：暂停任务轮播文字） |
| 番茄-专注 | 番茄饼图（可选叠倒计时分） | `🍅 14:32 · <任务标题>`（文案模式则 `专注中 · <标题>`） |
| 番茄-短休/长休 | 茶绿饼图（可选叠倒计时分） | `☕ 4:32` |

**交互（逐条）**：
- **左键按钮** → 隐藏窗口被激活（`changeEvent` 拦截 `ActivationChange`）→ 弹出速览
  面板（§3.2，锚定按钮几何中点上方），随即窗口 `hide()/show()` 复位释放前台焦点
  （1×1 离屏窗永不现身、不持续夺焦点）；
- **悬停** → 系统 tooltip 全量状态（0.5s）；
- **右键** → v1 走系统默认按钮菜单（空任务表）；菜单主入口仍是通知区辅助图标右键；
  日后可用 `ICustomDestinationList` 加「快速添加 / 开始专注 / 设置」三个 JumpList 任务；
- **Alt-Tab** → 会出现「ZenTray · <当前标签>」条目——v1 接受（选中它=聚焦=
  触发速览，反而多一条可达路径）；消除方案备案：`ITaskbarList3::SetTabOrder`
  把它挂为主窗 tab（进缩略图组、出 Alt-Tab 列表），首版不做。

**设置（系统页·Windows 段新增）**：
- 「任务栏中央显示」开关（默认开；关=退回仅通知区图标旧形态）；
- 「标签长度」8–32 字（默认 20，超长截断…）；
- 「长标题跑马灯」开关（默认关；开启回收旧分支 400ms 步进滚动）；
- 合并模式检测提示行 + 「前往任务栏设置」按钮。

**风险与边界**：多显示器/休眠恢复时 1×1 窗焦点抖动（旧分支已知，激活拦截里
hide/show 复位即缓解）；任务栏自动隐藏时按钮随任务栏收起（系统预期行为）；RDP 会话
按钮与托盘均正常；Explorer 崩溃重启后 QWidget 仍在，按钮自动回归（比通知区图标更稳，
无需重注册）。

### 3.1 通知区辅助图标逐状态（右下角）

位置：任务栏右下角通知区（Win11 默认在 `^` 溢出内，可拖出固定）。仅图标无文字。

| 状态 | 图标（QPainter 动态绘制） | Tooltip（悬停 0.5s） |
|---|---|---|
| 启动加载 | 单色 app 剪影 | 「ZenTray 启动中…」 |
| 任务轮播 | 优先级饼图（红/黄/绿环 + 子任务完成填充） | `[分类] 任务标题 · 子任务 3/5 · 优先级`（128 字符内） |
| 报告待查看（轮播交替） | app 彩色 icon + 右下角小红点徽标 | `📄 插件报告待查看: <名>` |
| 脚本运行 | app icon + 转圈弧（每 tick 步进） | `⚡ <插件名> 运行中…` |
| 番茄-专注 | 番茄饼图（红果+绿萼+填充）；可选拓展：图标内叠加 `24` 剩余分钟数字 | `🍅 专注 14:32 · <任务标题>` |
| 番茄-短休/长休 | 茶绿圆饼（+叠加剩余分钟） | `☕ 短休 4:32 剩余` |

轮播节奏沿用设置（各优先级秒数/模式）；报告轮播与任务**交替**，不占脚本/番茄优先级
——全部与 Linux 相同，只是呈现槽位从「顶栏文字」变为「图标+tooltip+速览面板」。

### 3.2 任务速览面板（左键单击弹出）——新增 `/glance` 路由

Windows 上「瞥一眼当前任务」的主入口。锚定托盘上方（右对齐屏幕右缘），**360×动态高**；
WS_EX_TOOLWINDOW + NOACTIVATE（不进任务栏、不抢 Alt-Tab、不夺焦点）；出现动画 100ms
淡入+上移 4px。

面板结构（自上而下，逐交互）：
```
┌────────────────────────────────────┐
│ ● ▲▔▔▔ 高优先 75%      ◀  ▶      │ ← 轮播槽大卡：饼图+优先级+子任务进度；
│ [工作-需求B] 编写交互设计文档        │    标题两行截断；◀▶ 手动切上一/下一任务
│ 子任务 3/5 · 截止 明天 18:00        │    （不重置自动轮播计时）
│ ──────────────────────────────────│
│ 🍅 专注中 14:32 · 今日 3 🍅/75min  │ ← 番茄态行（进行中才显示；点击=展开控制）
│    ⏭ 跳过休息   ➕ 延长   ⏹ 中止   │    三按钮随阶段切换（空闲时整行隐藏）
│ ──────────────────────────────────│
│ 📄 插件报告待查看: 内存分析  ×2    │ ← 报告 chips（点开报告即消；无则隐藏）
│ ──────────────────────────────────│
│ ✓ 完成    🍅 以此专注    ⚡ 快速添加 │ ← 快捷行（作用于当前轮播槽任务）
│ 📋 打开完整列表                     │
└────────────────────────────────────┘
```
- 轮播 tick 实时刷新大卡（与图标/tooltip 同源同拍）；手动 ◀▶ 只改显示不改调度。
- Esc / 点击面板外 / 再点托盘图标 → 关闭。
- 无任务时：大卡区显示空态「暂无活跃任务 — ⚡ 记一笔？」（点击=快速添加）。
- 勿扰模式吞掉 toast 时，这里是报告触达的兜底路径。

### 3.3 沿革：搁置分支 `feature/win-tray-title` 的废弃与复活

旧 `WindowsTaskbarTray`（1×1 隐藏窗口造任务栏按钮 + 标题跑马灯）曾因「Win11 默认
合并任务栏仅图标」被废弃。2026-10-07 产品重审：**托盘内容必须在任务栏中央完整显示**，
且 Win11 23H2+ 已恢复「从不合并」设置——方案复活并升级为 §3.0 主显示，新增合并模式
检测引导、左键速览接管、QPainter 动态图标、标签长度/跑马灯设置。rebase 该分支时
`WindowsTaskbarTray` 窗口机制与跑马灯逻辑直接回收，`tests/unit/test_tray.py` 单测改造
一并回收。

## 4. 右键菜单逐项设计

QMenu 原生渲染（Win11 圆角菜单元素），右键弹出；**默认动作加粗**（Windows 惯例）。
菜单可标注全局热键提示（仅提示，实际注册在 keyboard 层）。

**空闲态（默认）**：
```
────────────────────────────
 🍅 **专注 25mins · 今日 75mins**    ← 加粗默认项；点击=以默认时长开始未绑定专注
    （格式来自设置 menu_label_format：{focus}/{today}/{count} 占位）
────────────────────────────
 📋 任务列表
 ⚡ 快速添加…            Ctrl+Alt+T
 🧩 插件                          ← 启用且装了插件才出现（同 Linux 动态项）
────────────────────────────
 📜 历史…
 ⚙️ 设置
────────────────────────────
 ❌ 退出
```

**专注中**：
```
 🍅 专注中: <任务标题或「自由专注」>   ← 禁用信息项
 今日 🍅 3 · 75 分钟                  ← 禁用统计行
────────────────────────────
 ⏹ 中止专注（≥1 分钟记入历史）
 ⏱ 延长 10 分钟
────────────────────────────
（动作区/系统区同空闲；「专注」融合按钮此时不出现）
```

**休息中**：`⏭ 跳过休息`（替代中止/延长）；统计行保留。

**脚本运行中**：状态行 `⚡ <插件> 运行中…`；「专注」项禁用（双向拦截，同 Linux）；
速览面板同步禁用「🍅 以此专注」。

**无任务**：融合按钮下加禁用行「暂无活跃任务」。

## 5. 任务列表窗口

窗口：**908×640** 默认（可缩放，最小 760×560），原生标题栏 ─ □ ×（×=隐藏到托盘），
标题「ZenTray — 任务」。左侧任务列表视图复用 Vue（Qt 原生渲染 chrome）。

布局三段：顶部分段控件（活跃 / 周期 / 历史）+ 搜索框；左列任务卡列表（滚动）；
右列详情卡。（内容结构与 Linux/mac 完全同源，以下仅 Windows 呈现差异逐点。）

- **分段控件**：Win11 分段样式（圆角胶囊组，选中=纯白洗底+描边）。
- **搜索框**：Ctrl+F 聚焦；实时过滤标题/分类/备注；Esc 清空。
- **任务卡（逐交互）**：
  - 单击：选中，详情卡切换（左列选中态=主色 8% 洗底+2px 左缘条）。
  - 双击标题：等价「编辑」。
  - 右键：上下文菜单「编辑 / 完成 / 废弃 / 🍅 以此任务专注 / ▶ 运行关联插件」
    （Win32 上下文菜单元素，图标+文字）。
  - 悬停卡片右上角「✓」快捷完成（单击，含确认对话框——Windows 用原生任务对话框）。
- **详情卡（右列，逐按钮）**：
  - 头部：标题 + 分类标签 + 优先级色点 + 截止；逾期红字前缀。
  - 子任务区：复选框点击切换（划线动画）；行悬停「×」废弃；底部输入「添加子任务，回车确认」。
  - 进度条：子任务自动汇总；仅展示不可拖。
  - 操作行（按序）：`编辑` / `✓ 完成`（主色）/ `废弃`（灰）/ `🍅 专注`（实心主色）/
    `▶ 运行关联插件`（有关联才显示）。
  - 「AI 建议」卡（场景能力开启时）：建议两类——带「应用」按钮（提级/改截止/追加子任务，
    点击即生效刷新）与纯文本（「忽略」逐条消掉）。
- **新建/编辑（对话框窗，非 sheet）**：
  - 字段：标题（多行）、分类二级联动下拉、优先级分段、日期时间选择器（Windows 原生
    DateTimePicker 样式：日历下拉+上下键调节）、提醒开关+时间、关联插件下拉+「试运行」、备注。
  - 「📷 图片识别」：Windows 文件对话框选图 or **Ctrl+V 粘贴截图**（剪贴板位图，Windows
    截图工作流 Win+Shift+S 的自然衔接）；多条先选一条再进草稿。
  - 「✨ 智能解析」：一句话 → 草稿预览（逐字段确认）→「应用到表单」回填。
  - 底部：「取消」（Esc）/「保存」（Ctrl+↩）；保存时冲突检测弹窗（与其它任务/AI 调度
    时刻），「仍要保存」确认。

## 6. 快速添加（PowerToys Run 风格）

触发：**Ctrl+Alt+T**（全局，保留现网默认；设置页可改键）。

面板：**640×动态**，屏幕水平居中、垂直 38%（对齐 PowerToys Run / Cortana 肌肉记忆）；
无边框圆角 8px + 1px 描边 + 大投影；出现动画 120ms 缩放 0.96→1+淡入。

- 大输入框占满宽；placeholder「记一笔，回车保存…」。
- 输入即解析预览行：识别的截止/分类以灰色小标签显示在输入框下方。
- 「✨」按钮（非空点亮）：AI 解析 → 面板向下展开草稿卡（标题/分类/优先级/截止/子任务

- 保存后面板保持（连续记事）；Esc 或点外关闭。

## 7. 设置窗口

窗口 **880×620**（可缩放，最小 720×520），原生标题栏，Ctrl+, 打开。左导航 160px
（选中=主色洗底+左缘条），右侧内容区滚动——布局同现网。

侧栏（自上而下）：✨ AI 能力 / 🔔 通知 / 📋 任务 / 🍅 番茄钟 / 🧩 插件 / 🖥️ 系统 / 💾 备份 / 📜 历史。

各页逐控件（与 Linux 功能对齐，仅列 Windows 呈现差异）：

**✨ AI 能力**：顶部场景开关卡（智能解析/图片识别/任务建议，默认关）；标签页「每日计划 /
每日复盘 / 模型接入」。JobEditor：启用开关；时间选择（数字框+滚轮悬停调节）；跳过公休日；
保存本地；**完成通知渠道**复选组（应用弹窗=Windows toast / WxPusher，至少留一，空=全选）；
**报告托盘轮播**（开关+分钟数）；风格区（提示词可编辑，多 API 同时仅一启用，key 密码框
点击「👁 显式」切换明文——Windows 无 mac 的 ⌘⌥ 惯例，用显式眼睛按钮）。

**🔔 通知**：应用弹窗行（Windows 上=系统 toast；子行「在系统设置中配置通知/勿扰…」按钮
跳 `ms-settings:notifications`）；WxPusher 行（展开配 token/uid）。

**📋 任务**：各优先级停留秒数（滚轮可调）、轮播模式；逾期前缀与开关；分类管理
（括号/分隔符/二级开关/一二级增删改，行内编辑）。

**🍅 番茄钟**：节奏预设三卡（经典 25/5、深度 50/10、超长 90/20）；时长组（专注/短休/
长休/长休间隔/延长分钟，数字框+滚轮）；自动休息/自动专注；每日目标；**托盘图标叠加倒计时**
开关（Windows 专属：图标饼图内叠剩余分钟数字，默认关——小图标可读性因 DPI 而异）；
托盘右侧显示（倒计时/文案，仅 tooltip 生效说明）；菜单按钮融合文案输入框（占位符
{focus}/{today}/{count}，下方实时预览一行）。

**🧩 插件**：总开关卡（含**运行报告托盘轮播**开关+分钟、**脚本完成通知渠道**复选组）；
三大折叠块——📜 插件列表（默认展开：排序、逐插件授权/运行/编辑/删除/说明、展开调度
规则/参数预设；variadic 参数「＋ 加一条」增行）；📦 导入插件（默认收起，zip/目录，Windows
文件对话框选择，先预览校验再安装，同名询问覆盖）；🗂 运行历史（点行日志抽屉，行内「报告」
系统默认应用打开）。

**🖥️ 系统**（Windows 差异最大的一页）：
- 外观：跟随系统 / 浅色 / 深色三选一 + 浅色下 Neo 纸墨 / Aurora 冰璃双皮肤卡；深色单皮肤；
  标题栏深浅由 DWM 同步（说明行）。
- 动效开关；形状风格。
- **开机自启**：开关（HKCU Run 写/删；立即生效）；只读提示行「也可在 任务管理器 →
  启动应用 中管理」（不提供跳转——任务管理器无可编程入口）。
- **固定托盘图标**：按钮「在任务栏设置中固定图标…」→ 打开 `ms-settings:taskbar`；
  辅文说明 Win11 默认藏 `^` 溢出（Win10 无此问题则隐藏该行）。

**💾 备份**：五卡片——存储目录（「更改…」Windows 文件夹选择对话框（SHBrowseForFolder
原生样式）、「在资源管理器中显示」（explorer /select）、「恢复默认」）；手动备份（六项勾选
（含密钥项红标）、AES-256 密码框+显式眼睛、立即备份/另存为…（原生保存对话框，默认
zentray-backup-YYYYMMDD.zip）/仅打包归档）；自动周期（频率+时刻+保留份数）；从备份文件

**📜 历史**：只读单页，日期侧栏+合并时间轴+详情。

底部全局：「保存设置」主按钮（未保存变更时脉冲）+「取消」（还原未保存项）。

## 9. 通知（Windows 呈现）

- 形态：**系统 toast**（右下角滑入，5s 后收入通知中心）；来源=ZenTray（图标+应用名），
  正文=具体标题；勿扰/专注助手期间静默收藏进通知中心（不弹横幅但可回看）。
- **点击 toast**：打开对应报告（html→默认浏览器；md→默认应用）；AI 计划/复盘同。
- 通知中心：按 ZenTray 分组堆叠留存；「报告待查看」轮播与通知独立（点了 toast=已查看，
  轮播退出——`messageClicked` → `_pending_click` 回调链现网已备）。
- WxPusher 渠道不变（与 toast 并行，渠道多选控制各入口）。
- 与 mac 的差异：**无授权弹窗、无拒绝降级路径**（Windows toast 默认允许；被用户在系统
  设置关闭则同 notify-send 不可用行为，设置页黄条引导重开）。

## 12. 技术落点（给实现者）

1. `zentray/ui/tray.py` 新增 `WindowsTray(QtStandardTray)`：重载 `activated` 分流
   （Trigger/DoubleClick=速览面板；Context=菜单；Middle=快速添加彩蛋可选）；QPainter
   动态图标（饼图/番茄/茶绿/脚本转圈/报告徽标/倒计时叠加）；tooltip=全量状态；
   `create_tray_backend` 加 `sys.platform == "win32"` 分支。
1a. **任务栏中央按钮**（§3.0）：`WindowsTray` 内建 1×1 离屏 QWidget（frameless +
   WindowMinimizeButtonHint），`set_window_icon` 复用 `paint_tray_pixmap`，
   `set_window_title`=轮播标签（`_short_label` 截断），`changeEvent` 拦截激活→速览
   + hide()/show() 复位；启动读 `TaskbarGlomLevel` 判合并模式；机制回收
   `feature/win-tray-title` 的 `WindowsTaskbarTray`。
2. 速览面板：`web_host.py` 新路由 `/glance`（Vue 单页，轮询或 SSE 拿轮播槽）；Qt 侧
   frameless + `WS_EX_TOOLWINDOW|WS_EX_NOACTIVATE`，锚定 `QSystemTrayIcon.geometry()`
   （取不到则光标位）右对齐。
3. 通知：`QtStandardTray.show_notification` 已有 `_pending_click`——Windows 直用；
   toast 点击进报告链路零新增代码（验证 Win11 行为即可）。
4. 自启：`services/autostart.py` 按 `sys.platform` 加 HKCU Run 分支（文件头已预留扩展点）。
5. 热键：`keyboard` 库跨平台已可用，不动；失败回退提示文案 Win 化。
6. 对话框 chrome：`dialog_utils.py` Windows 分支设 DWM 深色标题栏；跳过 Linux 自研
   拖拽注入；Vue 数字输入补 wheel 事件（滚轮调数）。
7. 打包：PyInstaller onedir → Inno Setup 安装 exe + zip 便携；图标多尺寸 .ico；
   SmartScreen 未签名说明入 README。
8. 风险：Win11 溢出区藏图标（设置页引导固定）；高 DPI 图标糊（按 devicePixelRatio
   绘制）；勿扰吞 toast（速览面板 chips 兜底）；`keyboard` 库钩子被杀软误报（罕见；
   备选迁移 RegisterHotKey + 线程消息泵，接口不变）。
